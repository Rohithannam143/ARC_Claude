# ARC AI

An intelligent learning workspace for notes, documents, research and AI-assisted study.

## Stack

- React 18 + TypeScript
- Vite 6
- Lucide icons
- Responsive CSS design system

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Product modules

- Workspace dashboard and notes
- Document library and imports
- AI Study Room
- Summaries, flashcards and quizzes
- Search and export

The project is being rebuilt from a clean repository baseline. Integrations are added as isolated modules so the interface can run independently of backend availability.
